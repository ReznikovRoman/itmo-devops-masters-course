# Практикум: витрина для анализа LTV клиентов

## Контекст

Есть хранилище со схемой "звезда" (см. `init.sql`): `fact_sales` + измерения
`dim_customer`, `dim_product`, `dim_date`. Отдел маркетинга просит витрину,
чтобы за один SELECT увидеть, кто из клиентов приносит больше всего ценности.

## Задание
[task_ltv_view.md](task_ltv_view.md)
Спроектировать и написать `CREATE VIEW vw_customer_ltv`, которая для
**каждого клиента** возвращает:

- `customer_id`, `full_name`, `segment`, `city`;
- `total_amount` -- сумма всех покупок клиента;
- `orders_count` -- количество заказов (строк в `fact_sales`);
- `avg_order_amount` -- средний чек;
- `first_order_date`, `last_order_date`;
- `customer_lifetime_days` -- количество дней между первым и последним заказом.

## Условия

- Витрина должна быть обычным `VIEW` (не материализованным)
- Клиенты без единой покупки тоже должны попасть в витрину (с нулями /
  `NULL` в соответствующих полях) -- подумайте, какой тип `JOIN` для этого нужен.
